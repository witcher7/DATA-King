#### How to create dataframe
Dataframe is two dimensional structure with rows and columns and stores potentially large amount of data.
it is mutable like RDD.

df = spark.read.csv("path")
df = spark.read.json("path")
df = spark.read.parquet("path")
df = spark.read.jdbc("path")
df = spark.read.text("path")

> df.show() --> to show the dataframe 
> display(df) --> to show the dataframe in a table format
> df.show(10) --> to show the first 10 rows
> df.show(10, truncate=False) --> to show the first 10 rows without truncating
> df.show(10, truncate=50) --> to show the first 10 rows with 50 characters truncated

> Filter in pyspark
Pyspark filter() function is used to filter the rows in DataFrame based on certain conditions.
you can also use where() function which is an alias for filter().

df.filter(df["column1"] > 10).show()
# filter() is used to filter rows based on a condition

df.where(df["column1"] > 10).show()
# where() is used to filter rows based on a condition

> df.filter(df.address=="India").show()
> df.where(df.address!="India").show()

> df.filter((df.age > 25) & (df.name == "Alice")).show()
# & is used for AND operation
# | is used for OR operation
# ~ is used for NOT operation

df.filter(df.name.startswith("A")).show()
df.filter(df.name.endswith("e")).show()
df.filter(df.name.contains("li")).show()
df.filter(df.name.isin(["Alice", "Bob"])).show()
df.filter(df.name.isNull()).show()
df.filter(df.name.isNotNull()).show()
df.filter(df.name.like("%li%")).show()


## DISTINCT AND DROP DUPLICATES
Pyspark distinct() and dropDuplicates() methods are used to drop duplicate rows from DataFrame.
distinct() --> transformation used to drop/remove duplicate rows based on all columns
dropDuplicates() --> transformation used to drop/remove duplicate rows based on specified/selected columns

df1 = df.distinct() # removes duplicate rows based on all columns
df1.show()

df2 = df.dropDuplicates('emp_id','salary') # removes duplicate rows based on emp_id and salary columns
df2.show()


## GROUP BY
> it allows you to perform aggregate functions on groups of rows, rather than on individual rows,
enable you to calculate summary statistics for different categories within your data

## aggregate functions
count(), sum(), avg(), max(), min(), countDistinct(), approx_count_distinct(),mean(), stddev(), variance()
agg() function is used to apply aggregate functions to grouped data and calculate more than one aggregate value

Sum()
df.groupBy("address").sum("salary").show()
# sum() is used to calculate the sum of a column
# groupBy() is used to group rows by a column

Count()
df.groupBy("address").count().show()
# count() is used to count the number of rows in a column
# groupBy() is used to group rows by a column

Max()
df.groupBy("address").max("salary").show()
# max() is used to find the maximum value in a column
# groupBy() is used to group rows by a column

Min()
df.groupBy("address").min("salary").show()
# min() is used to find the minimum value in a column
# groupBy() is used to group rows by a column

Avg()
df.groupBy("address").avg("salary").alias("avg_salary").show()
# avg() is used to calculate the average of a column
# groupBy() is used to group rows by a column

.Alias
df.groupBy("address").agg({"salary": "sum"}).alias("total_salary").show()
# agg() is used to apply aggregate functions to grouped data
# alias() is used to give a column a different name


### JOINS IN SPARK 
INNER JOIN -> Returns rows that have matching values in both tables
LEFT JOIN -> Returns all rows from the left table, and matching rows from the right table
RIGHT JOIN -> Returns all rows from the right table, and matching rows from the left table
FULL OUTER JOIN -> Returns all rows from both tables
LEFT SEMI JOIN -> Returns rows from the left table that have a match in the right table
LEFT ANTI JOIN -> Returns rows from the left table that do not have a match in the right table

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "inner").show()
# join() is used to join two dataframes on a column
# == is used to compare two columns
# "inner" is used to specify the type of join

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "left").show()
# "left" is used to specify the type of join

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "right").show()
# "right" is used to specify the type of join

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "full").show()
# "full" is used to specify the type of join

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "left_semi").show()
# "left_semi" is used to specify the type of join

> emp_df.join(dept_df, emp_df.emp_id == dept_df.dept_id, "left_anti").show()
# "left_anti" is used to specify the type of join

> emp_df.join(dept_df, "emp_id", "full_outer").show()
# "emp_id" is used to specify the column to join on
# "full_outer" is used to specify the type of join



### UNION AND UNION ALL
UNION -> Returns all rows from both tables
UNION ALL -> Returns all rows from both tables, including duplicates

> emp_df.union(dept_df).show()
# union() is used to combine two dataframes
# union() is used to combine two dataframes with the same schema

> emp_df.unionAll(dept_df).show()
# unionAll() is used to combine two dataframes
# unionAll() is used to combine two dataframes with the same schema
