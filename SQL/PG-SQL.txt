CREATE TABLE customers(
 first_name VARHCAR(30) NOT NULL
 last_name VARCHAR(300) NOT NULL,
 email VARCHAR(60) NOT NULL,
 company VARCHAR(60) NULL,
 Street VARCHAR(50) NOT NULL,
 City VARCHAR(40) NOT NULL ,
 State CHAR(2) NOT NULL DEFAULT 'PA',
 Zip SMALLINT NOT NULL,
 PHONE VARCHAR(20) NOT NULL,
 Birth_date DATE NULL,
 SEX CHAR(1) NOT NULL,
 DATE_ENTERED TIMESTAMP NOT NULL,
 ID SERIAL PRIMARY KEY);
 
## > SQL SERVER id INT IDENTITY(1,1) PRIMARY KEY ----> 

SERIAL --> WHOLE NUMBER that also auto increment
  SmallSERIAL --> 1 to 32,767
  Serial --> 1 to 2,147,483,647

TIMESTAMP --> Timestamp is a data type that stores both date and time information as well zone.
It is used to record the exact moment an event occurs, making it useful for tracking changes and maintaining historical records in a database. In PostgreSQL, the TIMESTAMP data type can be used with or without time zone information, allowing for flexibility in how date and time data is stored and retrieved.

SELECT first_name,last_name, street, city, zip, birth_date 
FROM customers
WHERE EXTRACT(YEAR FROM birth_date) BETWEEN 1990 AND 2000
# Extract is used to retrive specific parts of a date or timestamp, such as the year, month, day, hour, minute, or second. 
In this case, it is used to filter customers whose birth dates fall within the years 1990 to 2000.
