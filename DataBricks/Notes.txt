## CATALOG
> This is the top level of organization in databricks which contains schemas and tables that are accessible to users
> Think of it as a database in traditional SQL databases and to access it you need proper permissions
> Helps to organize and secure data assets

Types of Catalogs:
1. Default Catalog - This is the default catalog that is created when you create a workspace / Standard Unity Catalog 
Data is stored in the workspace on cloud storage of your choice (AWS, Azure, GCP)

2. External Catalog - This is a catalog that is created from an external data source
Mount the external data source to the workspace and create a catalog from it 
for example, you can mount an S3 bucket to the workspace and create a catalog from it 
Foreign data is stored in the external data source MYSQL, Postgres, etc.

3. Unity Catalog - This is a catalog that is created from a Unity Catalog
In this case, data is stored in the Unity Catalog itself
